# 3D Dino Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **This project overrides that default.** It is a learning project: the owner wants each step explained in plain language *before* its code is written. Execute inline with superpowers:executing-plans, one task at a time, explanation first.

**Goal:** A 3D remake of the Chrome offline T-Rex runner — identical mechanics, real lit and shadowed 3D models, three-quarter camera.

**Architecture:** Vanilla JS modules on Three.js. The dino stays at x = 0 and only moves on Y; ground segments and obstacles travel toward it along -X and recycle once behind the camera. A delta-time loop drives a small state machine (`waiting` → `playing` → `gameover`). Pure logic (collision, spawn spacing, score) lives in dependency-free modules that are unit tested; everything visual is verified by playing it.

**Tech Stack:** Three.js, Vite, Vitest, vanilla JavaScript (ES modules). No framework, no physics library, no CDN.

## Global Constraints

- **No comments in source files.** Explanation belongs in conversation, never in code.
- **No AI-slop filler** — no defensive noise, no restating-the-obvious names, no abstractions with one caller.
- **Commits carry no `Co-Authored-By` trailer.**
- Each implementation step is explained in plain language before the code is written.
- All motion in units **per second**, never per frame. Delta clamped to 0.05 s.
- Assets are CC0 and committed to `public/models/`. No CDN, no network at runtime.
- Dino is fixed at x = 0. The world moves; the dino does not.
- Object pools everywhere — no allocation inside the play loop.
- Shared tuning constants live in `src/config.js` and are imported, never duplicated.

- [ ] **Step 1: Write `src/scene.js`**

```js
import * as THREE from 'three'

export function createScene(canvas) {
  const renderer = new THREE.WebGLRenderer({ canvas, antialias: true })
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))
  renderer.shadowMap.enabled = true
  renderer.shadowMap.type = THREE.PCFSoftShadowMap

  const scene = new THREE.Scene()
  scene.background = new THREE.Color('#dfe6e2')
  scene.fog = new THREE.Fog('#dfe6e2', 35, 70)

  const hemi = new THREE.HemisphereLight('#ffffff', '#8d8163', 0.9)
  scene.add(hemi)

  const sun = new THREE.DirectionalLight('#fff4e0', 1.7)
  sun.position.set(8, 14, 10)
  sun.castShadow = true
  sun.shadow.mapSize.set(2048, 2048)
  sun.shadow.camera.left = -12
  sun.shadow.camera.right = 20
  sun.shadow.camera.top = 12
  sun.shadow.camera.bottom = -8
  sun.shadow.camera.near = 1
  sun.shadow.camera.far = 45
  sun.shadow.bias = -0.0008
  scene.add(sun)
  scene.add(sun.target)

  const ground = new THREE.Mesh(
    new THREE.PlaneGeometry(200, 30),
    new THREE.MeshLambertMaterial({ color: '#cbbb99' })
  )
  ground.rotation.x = -Math.PI / 2
  ground.position.x = 40
  ground.receiveShadow = true
  scene.add(ground)

  function resize(width, height, camera) {
    camera.aspect = width / height
    camera.updateProjectionMatrix()
    renderer.setSize(width, height)
  }

  return { scene, renderer, sun, hemi, resize }
}
```

### Task 3: Camera rig

**Files:**
- Create: `src/camera.js`
- Modify: `src/main.js`

**Interfaces:**
- Consumes: nothing.
- Produces: `createCameraRig(width, height)` returning `{ camera, update(delta), punchIn(), reset(), resize(width, height) }`. `update` runs every frame and eases the camera toward its desired position. The optional drift at the end of this plan adds a second `speed` parameter.

- [ ] **Step 1: Write `src/camera.js`**

```js
import * as THREE from 'three'

const BASE_POSITION = new THREE.Vector3(-5, 3.5, 9)
const BASE_TARGET = new THREE.Vector3(3, 1.2, 0)

export function createCameraRig(width, height) {
  const camera = new THREE.PerspectiveCamera(45, width / height, 0.1, 200)
  const position = BASE_POSITION.clone()
  const target = BASE_TARGET.clone()
  const desired = BASE_POSITION.clone()

  camera.position.copy(position)
  camera.lookAt(target)

  function update(delta) {
    position.lerp(desired, 1 - Math.pow(0.001, delta))
    camera.position.copy(position)
    camera.lookAt(target)
  }

  function punchIn() {
    desired.set(-3.2, 2.6, 6.4)
  }

  function reset() {
    desired.copy(BASE_POSITION)
  }

  function resize(nextWidth, nextHeight) {
    camera.aspect = nextWidth / nextHeight
    camera.updateProjectionMatrix()
  }

  return { camera, update, punchIn, reset, resize }
}
```

- [ ] **Step 2: Write `src/assets.js`**

```js
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js'
import { SkeletonUtils } from 'three/examples/jsm/utils/SkeletonUtils.js'

const MANIFEST = {
  dino: '/models/dino.glb',
  bird: '/models/bird.glb',
  cactusSmall: '/models/cactus-small.glb',
  cactusLarge: '/models/cactus-large.glb'
}

export function cloneModel(gltf) {
  const root = SkeletonUtils.clone(gltf.scene)
  root.traverse((child) => {
    if (child.isMesh) {
      child.castShadow = true
      child.receiveShadow = false
    }
  })
  return root
}

export async function loadAssets(onProgress) {
  const loader = new GLTFLoader()
  const names = Object.keys(MANIFEST)
  const loaded = {}
  let done = 0

  for (const name of names) {
    loaded[name] = await loader.loadAsync(MANIFEST[name])
    done += 1
    if (onProgress) onProgress(done / names.length)
  }

  return loaded
}
```

### Task 4b: Biome forests (added mid-build, not in the original plan)

**Files:** `src/biomes.js`, `src/forest.js`, `src/menu.js`, `index.html`, `src/scene.js` (adds `setGround`)

Three selectable worlds — Savanna, Bamboo, Jurassic — chosen from a start menu before the world builds. Each defines a ground colour and a set of foliage kinds with counts, scale ranges and depth bands.

Two techniques carry it:
- **Tiling.** One 130-unit tile of forest is built and cloned; the two tiles cycle so only two group positions move per frame, regardless of tree count.
- **Instancing.** Each foliage kind becomes one `InstancedMesh` per source mesh, so draw calls scale with the number of *kinds*, not the number of trees. Tripling density cost 0 fps (57 fps before and after, headless).

Foliage sits only at negative z, strictly behind the play line, so it can never hide an incoming obstacle.

Consequences for later tasks:
- Task 9's `waiting` state begins after the biome is chosen, not at page load.
- Task 10 must reuse the existing `#loading` element and menu styling in `index.html` rather than adding a second one.
- Task 11's day/night must recolour the biome's ground via `setGround`, and should tint foliage per biome rather than assuming one palette.

### Task 5: Input

**Files:**
- Create: `src/input.js`
- Modify: `src/main.js`

**Interfaces:**
- Consumes: nothing.
- Produces: `createInput()` returning `{ jumpPressed, jumpHeld, duckHeld, anyPressed, consume() }`. The three `*Pressed` flags are edge-triggered and cleared by `consume()`, called once per frame after the game has read them.

- [ ] **Step 1: Write `src/input.js`**

```js
const JUMP_KEYS = ['Space', 'ArrowUp', 'KeyW']
const DUCK_KEYS = ['ArrowDown', 'KeyS']

export function createInput() {
  const state = {
    jumpPressed: false,
    jumpHeld: false,
    duckHeld: false,
    anyPressed: false
  }

  function press(code) {
    if (JUMP_KEYS.includes(code)) {
      if (!state.jumpHeld) state.jumpPressed = true
      state.jumpHeld = true
    }
    if (DUCK_KEYS.includes(code)) state.duckHeld = true
    state.anyPressed = true
  }

  function release(code) {
    if (JUMP_KEYS.includes(code)) state.jumpHeld = false
    if (DUCK_KEYS.includes(code)) state.duckHeld = false
  }

  window.addEventListener('keydown', (event) => {
    if (JUMP_KEYS.includes(event.code) || DUCK_KEYS.includes(event.code)) event.preventDefault()
    press(event.code)
  })

  window.addEventListener('keyup', (event) => release(event.code))

  window.addEventListener('touchstart', (event) => {
    const bottomHalf = event.touches[0].clientY > window.innerHeight / 2
    press(bottomHalf ? 'ArrowDown' : 'Space')
  }, { passive: true })

  window.addEventListener('touchend', () => {
    release('Space')
    release('ArrowDown')
  })

  window.addEventListener('blur', () => {
    state.jumpHeld = false
    state.duckHeld = false
  })

  state.consume = () => {
    state.jumpPressed = false
    state.anyPressed = false
  }

  return state
}
```

### Task 6: Player physics and animation

**Files:**
- Create: `src/player.js`
- Modify: `src/main.js`

**Interfaces:**
- Consumes: `src/config.js`, `cloneModel` from `src/assets.js`, the input object from Task 5.
- Produces: `createPlayer(gltf)` returning `{ object, update(delta, input), getBox(), die(), reset(), state }`. `getBox()` returns `{ x, y, width, height }` with `y` as the box centre. `state` is one of `running`, `jumping`, `ducking`, `dead`.

- [ ] **Step 1: Write `src/player.js`**

```js
import * as THREE from 'three'
import { cloneModel } from './assets.js'
import { FAST_FALL, GRAVITY, JUMP_CUT, JUMP_VELOCITY } from './config.js'

const RUN_BOX = { width: 0.9, height: 1.6 }
const DUCK_BOX = { width: 1.3, height: 0.8 }

export function createPlayer(gltf) {
  const object = cloneModel(gltf)
  object.rotation.y = Math.PI / 2

  const mixer = new THREE.AnimationMixer(object)
  const clips = {}
  for (const name of ['Run', 'Jump', 'Death']) {
    const clip = THREE.AnimationClip.findByName(gltf.animations, name)
    if (clip) clips[name] = mixer.clipAction(clip)
  }
  if (!clips.Run) clips.Run = mixer.clipAction(gltf.animations[0])
  if (clips.Death) {
    clips.Death.setLoop(THREE.LoopOnce)
    clips.Death.clampWhenFinished = true
  }

  let current = clips.Run
  current.play()

  let velocityY = 0
  let state = 'running'

  function play(next) {
    if (!next || next === current) return
    next.reset().play()
    current.crossFadeTo(next, 0.15, false)
    current = next
  }

  function update(delta, input) {
    if (state === 'dead') {
      mixer.update(delta)
      return
    }

    if (state !== 'jumping' && input.jumpPressed) {
      velocityY = JUMP_VELOCITY
      state = 'jumping'
      play(clips.Jump)
    }

    if (state === 'jumping') {
      if (!input.jumpHeld && velocityY > 0) velocityY *= JUMP_CUT
      velocityY -= GRAVITY * delta
      if (input.duckHeld) velocityY -= FAST_FALL * delta
      object.position.y += velocityY * delta
      if (object.position.y <= 0) {
        object.position.y = 0
        velocityY = 0
        state = input.duckHeld ? 'ducking' : 'running'
        play(clips.Run)
      }
      return
    }

    state = input.duckHeld ? 'ducking' : 'running'
    object.scale.y = state === 'ducking' ? 0.55 : 1
    mixer.update(delta)
  }

  function getBox() {
    const box = state === 'ducking' ? DUCK_BOX : RUN_BOX
    return {
      x: 0,
      y: object.position.y + box.height / 2,
      width: box.width,
      height: box.height
    }
  }

  function die() {
    state = 'dead'
    velocityY = 0
    play(clips.Death)
  }

  function reset() {
    state = 'running'
    velocityY = 0
    object.position.y = 0
    object.scale.y = 1
    play(clips.Run)
  }

  return { object, update, getBox, die, reset, get state() { return state } }
}
```

`object.scale.y` is a stand-in for a real duck clip. If the pack ships one, swap the scale line for `play(clips.Duck)`.

```js
import * as THREE from 'three'
import { DESPAWN_X, SEGMENT_COUNT, SEGMENT_LENGTH } from './config.js'

export function createWorld(scene) {
  const geometry = new THREE.PlaneGeometry(SEGMENT_LENGTH, 200)
  const material = new THREE.MeshLambertMaterial({ color: '#cbbb99' })
  const segments = []

  for (let i = 0; i < SEGMENT_COUNT; i += 1) {
    const segment = new THREE.Mesh(geometry, material)
    segment.rotation.x = -Math.PI / 2
    segment.position.x = DESPAWN_X + i * SEGMENT_LENGTH
    segment.receiveShadow = true
    scene.add(segment)
    segments.push(segment)
  }

  const span = SEGMENT_COUNT * SEGMENT_LENGTH

  function update(delta, speed) {
    for (const segment of segments) {
      segment.position.x -= speed * delta
      if (segment.position.x < DESPAWN_X - SEGMENT_LENGTH) {
        segment.position.x += span
      }
    }
  }

  function reset() {
    segments.forEach((segment, i) => {
      segment.position.x = DESPAWN_X + i * SEGMENT_LENGTH
    })
  }

  return { update, reset }
}
```

```js
import * as THREE from 'three'
import { cloneModel } from './assets.js'
import { DESPAWN_X, SPAWN_X } from './config.js'
import { nextGap, pickObstacle } from './spawn.js'

const CACTUS_SMALL = { width: 0.5, height: 1.0 }
const CACTUS_LARGE = { width: 0.7, height: 1.5 }
const BIRD = { width: 1.0, height: 0.8 }

export function createObstacles(scene, assets) {
  const pool = []
  const active = []
  let distanceToNext = SPAWN_X

  function take(kind, size) {
    const found = pool.findIndex((item) => item.kind === kind && item.size === size)
    if (found >= 0) return pool.splice(found, 1)[0]

    const source = kind === 'bird'
      ? assets.bird
      : (size === 'large' ? assets.cactusLarge : assets.cactusSmall)

    const object = cloneModel(source)
    scene.add(object)
    return { kind, size, object }
  }

  function spawn(score) {
    const choice = pickObstacle(score, Math.random)

    if (choice.kind === 'bird') {
      const item = take('bird', 'bird')
      item.object.visible = true
      item.object.position.set(SPAWN_X, choice.height, 0)
      item.box = { ...BIRD, offsetY: choice.height }
      active.push(item)
      return
    }

    for (let i = 0; i < choice.count; i += 1) {
      const size = Math.random() < 0.4 ? 'large' : 'small'
      const dimensions = size === 'large' ? CACTUS_LARGE : CACTUS_SMALL
      const item = take('cactus', size)
      item.object.visible = true
      item.object.position.set(SPAWN_X + i * 0.7, 0, 0)
      item.box = { ...dimensions, offsetY: dimensions.height / 2 }
      active.push(item)
    }
  }

  function update(delta, speed, score) {
    const travelled = speed * delta
    distanceToNext -= travelled

    if (distanceToNext <= 0) {
      spawn(score)
      distanceToNext = nextGap(speed, Math.random)
    }

    for (let i = active.length - 1; i >= 0; i -= 1) {
      const item = active[i]
      item.object.position.x -= travelled
      if (item.object.position.x < DESPAWN_X) {
        item.object.visible = false
        active.splice(i, 1)
        pool.push(item)
      }
    }
  }

  function boxes() {
    return active.map((item) => ({
      x: item.object.position.x,
      y: item.box.offsetY,
      width: item.box.width,
      height: item.box.height
    }))
  }

  function reset() {
    for (const item of active) {
      item.object.visible = false
      pool.push(item)
    }
    active.length = 0
    distanceToNext = SPAWN_X
  }

  return { update, boxes, reset }
}
```

```js
const FORGIVENESS = 0.85

export function overlaps(a, b) {
  const halfWidth = (a.width * FORGIVENESS + b.width * FORGIVENESS) / 2
  const halfHeight = (a.height * FORGIVENESS + b.height * FORGIVENESS) / 2
  return Math.abs(a.x - b.x) < halfWidth && Math.abs(a.y - b.y) < halfHeight
}

export function hitAny(box, boxes) {
  for (const other of boxes) {
    if (overlaps(box, other)) return true
  }
  return false
}
```

```js
import { SPEED_ACCEL, SPEED_MAX, SPEED_START } from './config.js'
import { hitAny } from './collision.js'

export function createGame({ player, obstacles, world, rig, input }) {
  let state = 'waiting'
  let speed = SPEED_START
  let distance = 0

  function start() {
    state = 'playing'
    speed = SPEED_START
    distance = 0
    player.reset()
    obstacles.reset()
    world.reset()
    rig.reset()
  }

  function update(delta) {
    if (state === 'waiting') {
      world.update(delta, SPEED_START * 0.3)
      player.update(delta, input)
      if (input.anyPressed) start()
      return
    }

    if (state === 'gameover') {
      player.update(delta, input)
      if (input.anyPressed) start()
      return
    }

    speed = Math.min(speed + SPEED_ACCEL * delta, SPEED_MAX)
    distance += speed * delta

    world.update(delta, speed)
    obstacles.update(delta, speed, 0)
    player.update(delta, input)

    if (hitAny(player.getBox(), obstacles.boxes())) {
      state = 'gameover'
      player.die()
      rig.punchIn()
    }
  }

  return {
    update,
    restart: start,
    get state() { return state },
    get speed() { return speed },
    get distance() { return distance }
  }
}
```

```js
const KEY = 'dino-high-score'

export function createScore(storage) {
  let raw = 0
  let value = 0
  let high = 0
  let milestone = false

  try {
    high = Number(storage.getItem(KEY)) || 0
  } catch (error) {
    high = 0
  }

  function add(distance) {
    const before = value
    raw += distance * SCORE_PER_UNIT
    value = Math.floor(raw)
    milestone = Math.floor(before / 100) !== Math.floor(value / 100) && value > 0
    if (value > high) {
      high = value
      try {
        storage.setItem(KEY, high)
      } catch (error) {
        high = value
      }
    }
  }

  function reset() {
    raw = 0
    value = 0
    milestone = false
  }

  return {
    add,
    reset,
    get value() { return value },
    get high() { return high },
    get milestone() { return milestone }
  }
}
```

- [ ] **Step 2: Write `src/audio.js`**

```js
const FILES = {
  jump: '/audio/jump.wav',
  milestone: '/audio/point.wav',
  death: '/audio/die.wav'
}

export function createAudio() {
  const buffers = {}

  for (const [name, path] of Object.entries(FILES)) {
    const element = new Audio(path)
    element.preload = 'auto'
    element.volume = 0.35
    buffers[name] = element
  }

  function play(name) {
    const element = buffers[name]
    if (!element) return
    element.currentTime = 0
    element.play().catch(() => {})
  }

  return {
    jump: () => play('jump'),
    milestone: () => play('milestone'),
    death: () => play('death')
  }
}
```
